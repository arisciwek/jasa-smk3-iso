# Konten lokal city

Setiap file JSON memakai nama slug city, misalnya `serang.json`.

```json
{
  "slug": "serang",
  "lastmod": "2026-10-08",
  "nextTopic": "karakteristik-lokal",
  "completedTopics": [],
  "paragraphs": []
}
```

`paragraphs` hanya berisi paragraf yang benar-benar relevan dengan kota. Generator tidak boleh mengubah paragraf lama, mengganti slug, atau menulis klaim lokal tanpa sumber.
